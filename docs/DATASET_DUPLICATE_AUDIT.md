# Duplicate record audit

- Dataset records: 48,086.
- Exact duplicate **feature-and-label rows** beyond the first occurrence: 74.
- Duplicate station ID + date pairs: 0.
- Decision: retain all records. Equal measured values and categories at different stations/dates do not prove duplicate observations. Removing these rows would change the benchmark population and require new evaluations.
- Dataset and provenance are unchanged; the previously verified evaluation figures therefore remain comparable.
