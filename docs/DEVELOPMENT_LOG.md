# AI Troubleshooting and Prompts Log

Prompts are reconstructed from development records where exact wording is unavailable.

## 1. Linker error when compiling
**Problem:** The build failed with an undefined reference to lround.
**Troubleshooting prompt (reconstructed):** The C files compile, but linking fails with "undefined reference to lround". Find the smallest Makefile change needed to fix this.
**Fix:** Linked the math library with -lm. The build then completed.

## 2. Custom air-quality labels
**Problem:** The first dataset used a custom formula and only three labels, which did not match Indian AQI categories.
**Troubleshooting prompt (reconstructed):** Replace the custom weighted score with CPCB pollutant breakpoint calculations and six AQI categories. Keep the calculator separate from kNN.
**Fix:** Added the separate AQI calculator and updated the classification categories.

## 3. Training data was artificial
**Problem:** The original readings were generated by code rather than collected at monitoring stations.
**Troubleshooting prompt (reconstructed):** Check whether the training CSV is synthetic. If real measurements are available, use them and explain their source clearly.
**Fix:** Replaced the default artificial training data with historical station-level measurements from the supplied dataset.

## 4. Missing lead readings
**Problem:** The historical source had no Pb column, but the console originally asked users to enter Pb.
**Troubleshooting prompt (reconstructed):** Remove Pb from active user input and training features, while keeping the remaining pollutants and AQI explanation consistent.
**Fix:** Changed the active model and console input to seven pollutants.

## 5. Small training sample
**Problem:** The first real-data versions used only 480, then 2,400 observations, despite more eligible rows being available.
**Troubleshooting prompt (reconstructed):** Check all station-day records. Keep readings with seven valid pollutant values and a known AQI category. Do not invent missing values.
**Fix:** Expanded the active dataset to 48,086 eligible station-day records.

## 6. Leave-one-out became slow
**Problem:** Running full leave-one-out evaluation on tens of thousands of records was too expensive for ordinary use.
**Troubleshooting prompt (reconstructed):** Keep normal predictions on the full training data, but make automatic k selection practical on a documented sample.
**Fix:** Used 1,200 sampled records for the k-selection/LOOCV procedure; normal prediction still uses the full training dataset.

## 7. Weighted kNN did not always win
**Problem:** An earlier hold-out comparison showed that distance-weighted voting was slightly less accurate than ordinary voting.
**Troubleshooting prompt (reconstructed):** Compare ordinary and distance-weighted kNN on the same test rows. Report both results even if the new method is worse.
**Fix:** Kept the comparison and reported the measured outcomes instead of assuming weighting improved accuracy.

## 8. Incomplete build ZIP
**Problem:** A six-file ZIP was missing required headers, helper C modules, tests and the Makefile.
**Troubleshooting prompt (reconstructed):** Check all source dependencies and package a complete C project that builds with Make.
**Fix:** Restored the missing dependencies, test files and build instructions.

## 9. Empty CSV fields shifted columns
**Problem:** Using strtok could skip empty CSV cells and move later values into the wrong positions.
**Troubleshooting prompt (reconstructed):** Review the CSV parser. Preserve empty column positions and reject invalid or incomplete rows.
**Fix:** Updated CSV parsing and added malformed-row tests.

## 10. Batch input validation was weaker
**Problem:** Batch readings could bypass some checks used for typed input.
**Troubleshooting prompt (reconstructed):** Apply the same number-count, finite-value and nonnegative checks to typed and batch readings.
**Fix:** Aligned validation between the two input paths.

## 11. Unfair normalization experiment
**Problem:** Raw kNN and normalized kNN had been evaluated on different numbers of rows.
**Troubleshooting prompt (reconstructed):** Compare raw and normalized kNN on exactly the same observations, labels and k.
**Fix:** Reworked the experiment to use the same 1,200 records; the recorded comparison was 75.08% raw and 75.25% normalized.

## 12. Test split was too easy to generalize from
**Problem:** The original interleaved split mixed nearby observations from the same monitoring stations.
**Troubleshooting prompt (reconstructed):** Add a test using stations absent from training and another using later dates. Keep scaling and k selection within training data.
**Fix:** Added unseen-station and future-year evaluations alongside the original hold-out.

## 13. Possible duplicate observations
**Problem:** Some rows had identical pollutant measurements and category labels.
**Troubleshooting prompt (reconstructed):** Check repeated measurement rows against station IDs and dates before deleting anything.
**Fix:** Found 74 repeated measurement-and-label rows but no duplicate station/date pairs; retained the rows.

## 14. Old test counts remained in documents
**Problem:** Some reports still mentioned 24 or 31 checks after more tests had been added.
**Troubleshooting prompt (reconstructed):** Find outdated test counts and mark historical reports clearly. Create one current verification record.
**Fix:** Updated the current verification record and distinguished older outputs from current results.

## 15. Console menu accepted invalid text
**Problem:** The menu used atoi, so nonnumeric input could be treated as zero.
**Troubleshooting prompt (reconstructed):** Replace atoi with checked numeric parsing. Reject text, decimals and overly long menu entries without accidentally exiting.
**Fix:** Used checked strtol and safer full-line handling.

## 16. Large values risked integer overflow
**Problem:** Large finite pollutant concentrations could overflow fixed-point normalization calculations.
**Troubleshooting prompt (reconstructed):** Review intermediate arithmetic in fixed-point normalization and add regression tests for large values.
**Fix:** Adjusted the conversion to calculate a safe normalized ratio before converting to Q8.

## 17. Startup failure could leak memory
**Problem:** An allocation failure during startup did not release every object already allocated.
**Troubleshooting prompt (reconstructed):** Review all startup failure paths and free any earlier allocations before returning.
**Fix:** Corrected the affected cleanup path.

## 18. AQI values above published breakpoints
**Problem:** The calculator needed to explain how it handles concentrations above the highest listed CPCB breakpoint.
**Troubleshooting prompt (reconstructed):** Check the highest AQI breakpoints and document how out-of-range values are handled. Do not describe an approximation as an official extrapolation.
**Fix:** Clarified the limit and behaviour in the code and README.

## 19. Final result reports did not agree
**Problem:** Old benchmark outputs were stored beside the current results.
**Troubleshooting prompt (reconstructed):** Run the final tests and benchmark modes and save one clearly labelled final verification report.
**Fix:** Recorded 41 passing checks and the final evaluation figures in FINAL_VERIFICATION.txt.
